## Customize without editing Lua

Choose a named action, inspect its current shortcuts, and select add, replace, or restore defaults. Enter a combination such as &lt;leader&gt;xf or &lt;F6&gt;. Changes apply immediately and persist.

The menu configures normal-mode actions. Conflicting mappings are reported. Native single-key motions and Ctrl W commands are protected. LSP actions are in the same menu.

## Terminal limits

Some terminals cannot distinguish Ctrl Shift F from Ctrl F, or capture Ctrl S. Use leader alternatives when necessary. Ctrl S also works in insert and visual modes.

LSP navigation and hover require a server supporting the relevant capability. Text replacement opens a two-field dialog with visible one/all buttons; it is separate from LSP symbol renaming.

## Panels, buffers, and terminals

Press F1 for a guide that reflects your configured shortcuts. Ctrl H/J/K/L moves between visible panes in normal mode and Forge terminals; h/j/k/l stays native in files. In the explorer, h collapses and l or Enter opens. Mouse clicks focus panels and double-clicks activate their actions.

| Action                    | Keys                                                         |
| ------------------------- | ------------------------------------------------------------ |
| Files / Agents / Chat     | Ctrl B / Leader p a / Leader p c                             |
| Next / previous buffer    | Ctrl Tab / Ctrl Shift Tab; Leader b n / Leader b p           |
| Terminal / new terminal   | Ctrl backtick / Ctrl Shift backtick; Leader o t / Leader o T |
| Split / choose terminal   | Ctrl Shift 5 / Leader o s; Leader o o                        |
| Review / debug / logs     | Leader p r / Leader p d / Leader p l                         |
| Settings / startup panels | Leader u s / Leader u L                                      |

## Resize panes

Focus a pane with Ctrl H/J/K/L. Ctrl Shift arrows move its divider in the arrow
direction. Leader w h/l moves it left/right; Leader w k/j moves it up/down.
Leader w = balances sizes. The direction stays the same from either side of a divider.

### Terminal on macOS

If only Leader works, configure Terminal > Settings > Profiles > Keyboard. Add
Control + Shift with each arrow, choose **Send Escape Sequence**, and enter:

| Arrow | Escape sequence (without the initial Escape) |
| ----- | -------------------------------------------- |
| Left  | `[1;6D`                                      |
| Right | `[1;6C`                                      |
| Up    | `[1;6A`                                      |
| Down  | `[1;6B`                                      |

If macOS opens Mission Control instead, review that shortcut in macOS Keyboard
settings. ForgeVim cannot receive a key that the operating system handles first.
See [Apple's custom-key instructions](https://support.apple.com/guide/terminal/trml108/mac).
