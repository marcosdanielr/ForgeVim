## File tree

Leader b toggles the project tree. Enter opens a file; a creates, r renames, and d requests deletion with confirmation. g? shows shortcuts. The tree opens beside project files. Ctrl H/L moves between panels; h/j/k/l moves the cursor.

## Stage and commit

Tab expands files, s stages, and u unstages. Press c for the commit popup, then c to open the message editor. Review staged content, write your commit message, save, and close as Neogit instructs.

Forge never commits or pushes automatically. Hooks, signing, and identity follow your Git configuration. Prefer lazygit? :ForgeLazygit opens your installed CLI in a native terminal tab.

<CodeBlock code={':ForgeGit'} />

## Three-way conflict resolution

The command checks for unmerged files before opening the merge. ]x and [x navigate conflicts. Leader c o chooses ours/current, Leader c t chooses theirs/incoming, and Leader c b chooses the base at the selected conflict.

Edit the result directly to combine both sides. Save, review, and stage only resolved files. :ForgeDiff opens working-tree review at any time.

> Choosing a side is your decision. No conflict is resolved automatically.

## Find, navigate, and replace

1. Press **Leader f b** to find in this file. **Leader f r** searches the project.
2. Type in **Find**, press **Tab**, then type in **Replace with**.
3. Press **Tab** to visit each checkbox and button. **Space** or **Enter** toggles the focused option.
4. Use **Previous** and **Next / skip** to inspect occurrences without changing them.
5. Choose **Replace one** to change this occurrence and advance. The window stays open. Repeat or skip as needed.
6. Choose **Replace all** only when you want every match changed. Confirm explicitly; Cancel is the default.

The selected occurrence is highlighted in the source split without taking your
focus. **Enter in Find, Replace with, or results moves to the next match**; it
does not close the dialog. File search includes unsaved text. Save before applying
replacements so pending work is never silently written.

| Key                        | Action                                 |
| -------------------------- | -------------------------------------- |
| Tab / Shift Tab            | Visit each field, checkbox, and button |
| Space / Enter on an option | Toggle that option                     |
| Enter / F3                 | Next match without replacing           |
| Shift Enter / Shift F3     | Previous match                         |
| Ctrl R                     | Replace selected match and advance     |
| Ctrl A                     | Ask to replace all                     |
| Ctrl Enter in results      | Open result and close the dialog       |
| F2                         | Focus Replace with                     |
| F8 / Alt C                 | Toggle match case (Aa)                 |
| F4 / Alt W                 | Toggle whole word                      |
| F5 / Alt R                 | Toggle regex search                    |
| F6                         | Toggle file/project scope              |
| Esc                        | Leave typing; press again to close     |

In results, **y** replaces and advances, **n** skips, and **N** goes back.

Replacement is literal: `$1` does not expand groups. Empty replacement removes
the match. Changed results and unsaved target buffers block application. Refine
searches with more than 2000 occurrences before replacing all.
