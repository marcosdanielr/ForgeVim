## File tree

Ctrl B or Leader f e toggles the project tree. Enter opens a file; a creates, r renames, and d requests deletion with confirmation. g? shows shortcuts. The tree opens beside the welcome screen. Ctrl H/L moves between panels; h/j/k/l moves the cursor.

## Stage and commit

Tab expands files, s stages, and u unstages. Press c for the commit popup, then c to open the message editor. Review staged content, write your commit message, save, and close as Neogit instructs.

Forge never commits or pushes automatically. Hooks, signing, and identity follow your Git configuration. Prefer lazygit? :ForgeLazygit opens your installed CLI in a native terminal tab.

## Three-way conflict resolution

The command checks for unmerged files before opening the merge. ]x and [x navigate conflicts. Leader c o chooses ours/current, Leader c t chooses theirs/incoming, and Leader c b chooses the base at the selected conflict.

Edit the result directly to combine both sides. Save, review, and stage only resolved files. :ForgeDiff opens working-tree review at any time.

<CodeBlock code={':ForgeConflicts'} />

> Choosing a side is your decision. No conflict is resolved automatically.

## Find and replace

1. Press **Leader f r** for the project, or **Leader f R** for the current file.
2. Type in **Find**. Results appear without changing files.
3. Press **Tab** and type the new text in **Replace with**. Both fields stay visible.
4. Select an occurrence in the results using the mouse, or Tab to results and use the arrows.
5. Click **Replace one** to change that occurrence. Click **Replace all**, then confirm, to change every result.

Prefer the keyboard? Tab to **Actions**, select a button with Left/Right, and
press Enter. **Cancel** is initially selected in the confirmation, so Enter alone
does not replace everything.

| Key              | Action                                    |
| ---------------- | ----------------------------------------- |
| Tab / Shift Tab  | Move between fields, results, and buttons |
| Ctrl R           | Replace one occurrence                    |
| Ctrl A           | Ask to replace all                        |
| F2               | Focus Replace with                        |
| F3               | Toggle match case (Aa)                    |
| F4               | Toggle whole word                         |
| F5               | Toggle regex search                       |
| F6               | Toggle file/project scope                 |
| Enter in results | Open the selected file                    |
| Esc              | Leave typing; press again to close        |

The options are also clickable. Replacement text is literal: `$1` does not
expand capture groups. An empty replacement deletes the selected match. Files
with unsaved edits and results that changed after searching are blocked. With
more than 2000 occurrences, refine the query before replacing all.
