## Themes, plugins, and shortcuts

Theme selection applies and persists. Tokyo Night is the default; Catppuccin, Rose Pine, and the plain Habamax theme are available too.

Toggle optional plugins or add a trusted GitHub owner/repository. Restart to install or unload choices; :Lazy shows versions and progress. Plugins execute code, so choose repositories you trust.

## Completion and Copilot

blink.cmp provides LSP, path, snippet, and buffer completion. Copilot is optional. Enable it in the plugin menu, restart, then run :Copilot auth.

Alt L accepts inline Copilot suggestions. Enter accepts a completion-menu item. Tab remains available for snippets and indentation. Copilot completion and agent tasks have separate authentication.

## Personal settings

The config path respects XDG_CONFIG_HOME. Menu preferences live under stdpath("state")/forge/preferences.json and override user defaults. Folder and language icons are enabled by default. Select a Nerd Font in your terminal, such as MesloLGM Nerd Font Mono. Use :ForgeIcons (Leader u i) and restart to switch to plain text.

## Bottom statusbar

The global bottom bar stays visible across panels. It shows mode, Git branch, errors and warnings, language, encoding, line endings, and cursor position. Counts come from actual buffer diagnostics.

Press K (Shift K) in normal mode for symbol documentation. Press gl or Leader c e for line errors and warnings. Use ]d and [d to move between diagnostics. F1 lists your configured keys; language documentation requires an active LSP.

## Window size and Leader

Pane headers show the shortcut that hides them. Leader b toggles Explorer; Leader p a toggles Agents, Leader p c toggles chat, and Leader p l toggles logs. Leader o t toggles terminals.

Focus a split with Ctrl H/J/K/L. Ctrl Shift Left/Right changes its width; Ctrl Shift Up/Down changes its height. Leader w h/l/k/j provides the same actions; Leader w = balances windows. Mouse resizing remains available.

Leader defaults to Space. :ForgeLeader or Settings saves a different key; restart applies it. Leader Leader opens commands. Leader ] / Leader [ cycles buffers; terminal Tab completion remains available.

Find files with Leader f f, search project text with Leader f g, and search the current buffer with Leader f b. :ForgeKeymaps changes these keys. :ForgeDiagnosticDisplay selects inline, expanded current-line, or quiet error messages.

## New terminals, pane toggles and replacement

Leader o t toggles the active terminal. Leader o T creates another shell; Leader o s splits and Leader o o lists sessions. New, Split and List are also clickable in the terminal header. Ctrl Space keeps code completion available.

Leader p a toggles Agents, Leader p c toggles chat, Leader p l toggles logs, and Leader b toggles Explorer. Inside a CLI chat or terminal, press Esc twice before using Leader shortcuts. Spaces and text are sent to the CLI unchanged while typing. Hiding a terminal keeps its process running.

Use **Leader p m** while a Forge panel is focused to move it. Four outlined,
numbered zones appear over the editor: click a zone or choose **1** left, **2**
right, **3** below, or **4** above. Forge restores that placement after the panel is
hidden. Use **Leader s v** for a vertical source-buffer split
and **Leader s h** for a horizontal split.

Replacement keeps Find and Replace with visible in a floating dialog. Tab moves between fields, results, and clickable one/all buttons. Ctrl R applies one occurrence; Ctrl A asks to apply all.

## Configure from the editor

Open Settings with Leader u s. Choose theme, keyboard shortcuts, languages, plugins, account login, notifications, or startup layout. No Lua edit is required for these choices.

Startup layout can enable or disable the welcome screen, files sidebar, and Agents sidebar. Narrow terminals keep panels available by shortcut instead of opening every pane.

## Terminal sessions at a glance

The terminal list appears beside the lower shell panel on screens at least 80
columns wide. **Leader o o** focuses it. Use **j/k** and **Enter** to choose a
session; **n** creates a shell, **s** splits, and **q** hides only the list. Selecting
a visible shell focuses its existing split. Hidden sessions retain their buffers.

**Leader o t** hides/restores the whole terminal group. **Leader o T** creates and
**Leader o s** splits. Inside a shell, Esc Esc returns to terminal-normal mode;
then Leader ] / Leader [ cycles sessions, and Leader shortcuts are available.
When space is tight, splitting may hide Agent logs to preserve usable shell widths.
