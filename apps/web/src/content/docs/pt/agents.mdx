## O que o agente faz?

Um agente pode ler código, editar arquivos e executar ferramentas, como testes, conforme as permissões da CLI.
ForgeVim dá a cada tarefa uma **cópia Git separada** do projeto. Você revisa as mudanças antes de aplicar.

Uma **conversa de agente** é uma conversa contínua em Codex, Claude Code ou Gemini.
ForgeVim mostra o provedor e mantém a cópia Git isolada ligada à conversa.
**Autocomplete** sugere código durante a digitação; é independente dos agentes.

## 1. Instale uma CLI de IA

Escolha apenas uma para começar. Siga o guia oficial de instalação:

- [Codex CLI](https://developers.openai.com/codex/cli/) — comando: `codex`.
- [Claude Code](https://code.claude.com/docs/en/overview) — comando: `claude`.
- [Gemini CLI](https://geminicli.com/docs/get-started/installation/) — comando: `gemini`.

Use sua própria conta do provedor. ForgeVim não inclui assinatura de IA.

## 2. Faça login

Dentro do ForgeVim, pressione Esc e execute:

<CodeBlock code=":ForgeAgentConnect" label="Dentro do ForgeVim" />

Escolha o provedor e conclua o login. Ao terminar, pressione **Esc duas vezes**, depois `:q` para fechar a janela.

> **Successfully logged in** significa que a autenticação funcionou. Isso ainda não inicia um chat.

## 3. Salve e prepare o projeto

Use `:wa` para salvar todos os arquivos. Depois faça **commit ou stash** das alterações Git.
Abra `:ForgeGit` se precisar selecionar arquivos e fazer commit.
O agente começa no último commit; mudanças sem salvar ou sem commit não entram na cópia.

## 4. Inicie uma conversa de agente

<CodeBlock code=":ForgeAgentStart" label="Dentro do ForgeVim · atalho: Leader a n" />

1. Escolha Codex, Claude Code ou Gemini.
2. Dê um nome à conversa.
3. Aguarde a CLI aparecer à direita. Digite seu pedido e envie.

Comece com algo pequeno:

<CodeBlock
  code={`Adicione duas tentativas à requisição do cliente.
Preserve a interface pública.
Execute os testes relevantes e explique as mudanças.`}
  label="Exemplo de pedido"
/>

Continue a conversa no mesmo painel. O título mostra o provedor selecionado: uma
conversa Claude abre Claude Code, não Codex. O provedor pode pedir permissão para executar ferramentas.
**Ctrl H/J/K/L** troca de painel sem enviar texto ou parar o agente. Para outros
atalhos do editor, pressione **Esc duas vezes** antes. **i** volta à digitação.
**Leader p c** mostra ou oculta o chat; ocultar mantém a conversa ativa enquanto ForgeVim estiver aberto.

## 5. Execute tarefas em segundo plano

Abra `:ForgeAgents`, então pressione `b` para iniciar um pedido único em outra cópia do projeto.
Repita para tarefas independentes.
Por exemplo, uma pode investigar um teste falhando enquanto outra documenta um módulo separado.

<CodeBlock code=":ForgeAgents" label="Acompanhar tarefas e escolher ações" />

São agentes independentes. Selecione uma tarefa concluída e escolha
**Continue in provider conversation** para conversar no mesmo worktree.
ForgeVim não inventa uma equipe nem coordena seus planos automaticamente.
Revise cada resultado e faça commit das alterações aceitas antes de aceitar a próxima tarefa.

## 6. Revise antes de aplicar

1. Finalize o chat pela própria CLI. Abra `:ForgeAgents`.
2. Selecione a tarefa finalizada e escolha **Review changes**.
3. Leia o diff. Linhas adicionadas e removidas mostram o que mudou.
4. Pressione **a** e confirme para aplicar, **r** para rejeitar ou **q** para sair sem decidir.

**Aplicar não faz commit.** Confira os arquivos no projeto e faça commit quando estiver satisfeito.
Se o projeto ou o resultado mudou após a revisão, revise novamente. Resultados conflitantes continuam disponíveis para inspeção.

## Se algo não abrir

| Situação                       | O que fazer                                                     |
| ------------------------------ | --------------------------------------------------------------- |
| CLI not installed              | Instale a CLI escolhida e reabra o terminal.                    |
| Save buffers / Commit or stash | Salve os arquivos e organize as alterações Git.                 |
| Process exited 0 após login    | Execute :ForgeAgentStart; o login já foi concluído.              |
| Chat está oculto               | Esc duas vezes, depois Leader p c.                              |
| Espaço aciona atalhos          | Atualize e reinicie ForgeVim. Na CLI, pressione i para digitar. |

## Notificações e autocomplete

`:ForgeNotifications` ativa/desativa avisos de tarefas dentro do editor.
Copilot é independente: habilite-o em `:ForgePlugins`, reinicie e execute `:Copilot auth`.
**Alt L** aceita uma sugestão do Copilot. O autocomplete normal do LSP funciona sem ele.

## Reabrir saída salva

Reabra o mesmo projeto Git original, execute `:ForgeAgents`, selecione a conversa
e pressione **L**, ou escolha **View saved conversation output**. Os registros e
a saída bruta da CLI ficam no diretório ignorado `.forge` do projeto. O painel
carrega os últimos 256 KiB; esses logs não são uma transcrição organizada do chat.

Ocultar o chat mantém o processo enquanto ForgeVim estiver aberto. Fechar o editor
encerra a conexão com aquele terminal. Depois é possível consultar a saída salva.
Tarefas em segundo plano concluídas podem abrir uma nova conversa do provedor no worktree existente.
