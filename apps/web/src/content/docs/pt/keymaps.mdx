## Personalize sem editar Lua

Escolha uma ação pelo nome, veja os atalhos atuais e selecione adicionar, substituir ou restaurar padrões. Digite combinações como &lt;leader&gt;xf ou &lt;F6&gt;. As mudanças são aplicadas na hora e salvas.

O menu configura ações em modo normal. Conflitos com outros mapeamentos são sinalizados. Movimentos de uma tecla e comandos Ctrl W são protegidos.

## Área de transferência do sistema

`y` e `p` usam a área de transferência do sistema por padrão. No modo visual, **Ctrl C**, **Ctrl Shift C** ou **Cmd C** copia; **Ctrl V**, **Ctrl Shift V** ou **Cmd V** cola. No Terminal.app, Cmd C/V pode ser capturado pelo terminal antes de chegar ao Neovim; Ctrl C/V é o mapeamento confiável do Forge.

## Limites do terminal

Comandos do Forge usam Leader. Ctrl S também funciona em inserção e visual; Ctrl H/J/K/L continua focando painéis.

Para renomear símbolos, prefira F2 com um LSP ativo. Substituição textual abre uma janela com dois campos e botões para uma ou todas as ocorrências. Ela é independente da renomeação de símbolos pelo LSP.

> Os atalhos com Ctrl e função são mapeados em modo normal. Ctrl S também funciona nos modos de inserção e visual. Ctrl W continua controlando janelas.

## Painéis, buffers e terminais

F1 abre um guia com seus atalhos configurados. Ctrl H/J/K/L alterna os painéis no modo normal e nos terminais do Forge; h/j/k/l continua nativo nos arquivos. Na árvore, h recolhe e l ou Enter abre. Clique para focar e dê dois cliques para ativar ações dos painéis.

| Ação                            | Teclas                                                 |
| ------------------------------- | ------------------------------------------------------ |
| Arquivos / Agentes / Chat       | Leader b / Leader p a / Leader p c                     |
| Próximo / anterior buffer       | Leader ] / Leader [                                    |
| Terminal / novo terminal        | Leader o t / Leader o T                                |
| Dividir / escolher terminal     | Leader o s / Leader o o                                |
| Dividir buffer atual            | Leader s v / Leader s h                                |
| Mover janela focada             | Leader w m, depois 1 esquerda / 2 direita / 3 abaixo / 4 acima |
| Revisão / debug / logs          | Leader p r / Leader p d / Leader p l                   |
| Configuração / painéis iniciais | Leader u s / Leader u L                                |

## Redimensionar painéis

Foque o painel com Ctrl H/J/K/L. Ctrl Shift + setas move a divisória na direção
da seta. Leader w h/l move para esquerda/direita; Leader w k/j, para cima/baixo.
Leader w = equilibra os tamanhos. A direção é a mesma dos dois lados da divisória.

### Terminal do macOS

Se apenas o Leader funciona, abra Terminal > Ajustes > Perfis > Teclado. Adicione
Control + Shift com cada seta, escolha **Enviar sequência de escape** e informe:

| Seta     | Sequência (sem o Escape inicial) |
| -------- | -------------------------------- |
| Esquerda | `[1;6D`                          |
| Direita  | `[1;6C`                          |
| Cima     | `[1;6A`                          |
| Baixo    | `[1;6B`                          |

Se o macOS abrir o Mission Control, revise esse atalho nos ajustes de Teclado
do sistema. O ForgeVim não recebe teclas interceptadas pelo sistema operacional.
Veja as [instruções da Apple](https://support.apple.com/guide/terminal/trml108/mac).
