## Árvore de arquivos

Ctrl B ou Leader f e alterna a árvore do projeto. Enter abre um arquivo; a cria, r renomeia, d solicita exclusão com confirmação. Use g? para ver atalhos. A árvore abre ao lado da tela inicial. Ctrl H/L alterna os painéis; h/j/k/l move o cursor.

<CodeBlock code={':ForgeTree'} />

## Stage e commit com Neogit

Use Tab para expandir arquivos, s para stage e u para unstage. A tecla c abre o popup de commit; c novamente abre o editor da mensagem. Revise o conteúdo staged, escreva sua mensagem de commit, salve e feche conforme as instruções do Neogit.

Forge não faz commit ou push automaticamente. Hooks, assinatura e identidade seguem sua configuração Git.

<CodeBlock code={':ForgeGit'} />

## Conflitos em três vias

Abra o merge somente quando houver arquivos em conflito. ]x e [x navegam conflitos. Leader c o aceita ours/current; Leader c t aceita theirs/incoming; Leader c b aceita a base no conflito selecionado.

Edite o resultado diretamente quando precisar combinar os lados. Salve, revise e faça stage apenas dos arquivos resolvidos. :ForgeDiff abre a revisão de alterações a qualquer momento.

<CodeBlock code={':ForgeConflicts'} />

> Escolher um lado é sempre sua decisão. Nenhum conflito é resolvido automaticamente.

## Buscar e substituir

1. Pressione **Leader f r** para o projeto, ou **Leader f R** para o arquivo atual.
2. Digite em **Find**. Os resultados aparecem sem alterar arquivos.
3. Pressione **Tab** e digite o novo texto em **Replace with**. Os dois campos ficam visíveis.
4. Selecione uma ocorrência com o mouse, ou use Tab para chegar aos resultados e navegue com as setas.
5. Clique em **Replace one** para alterar aquela ocorrência. Clique em **Replace all** e confirme para alterar todos os resultados.

Prefere teclado? Use Tab até **Actions**, selecione o botão com Esquerda/Direita e
pressione Enter. **Cancel** começa selecionado na confirmação; Enter sozinho não
substitui tudo.

| Tecla                | Ação                                     |
| -------------------- | ---------------------------------------- |
| Tab / Shift Tab      | Alternar campos, resultados e botões     |
| Ctrl R               | Substituir uma ocorrência                |
| Ctrl A               | Pedir substituição de todas              |
| F2                   | Focar Replace with                       |
| F3                   | Alternar maiúsculas/minúsculas (Aa)      |
| F4                   | Alternar palavra inteira                 |
| F5                   | Alternar busca por regex                 |
| F6                   | Alternar escopo arquivo/projeto          |
| Enter nos resultados | Abrir o arquivo selecionado              |
| Esc                  | Sair da digitação; novamente para fechar |

As opções também aceitam clique. A substituição usa texto literal: `$1` não
expande grupos. Deixe o novo texto vazio para remover a ocorrência. Arquivos com
edições não salvas e resultados alterados após a busca são bloqueados. Com mais
de 2000 ocorrências, refine a busca antes de substituir tudo.
