## Árvore de arquivos

Leader b, Ctrl B ou Leader f e alterna a árvore do projeto. Enter abre um arquivo; a cria, r renomeia, d solicita exclusão com confirmação. Use g? para ver atalhos. A árvore abre ao lado da tela inicial. Ctrl H/L alterna os painéis; h/j/k/l move o cursor.

<CodeBlock code={':ForgeTree'} />

## Stage e commit com Neogit

Use Tab para expandir arquivos, s para stage e u para unstage. A tecla c abre o popup de commit; c novamente abre o editor da mensagem. Revise o conteúdo staged, escreva sua mensagem de commit, salve e feche conforme as instruções do Neogit.

Forge não faz commit ou push automaticamente. Hooks, assinatura e identidade seguem sua configuração Git.

<CodeBlock code={':ForgeGit'} />

## Conflitos em três vias

Abra o merge somente quando houver arquivos em conflito. ]x e [x navegam conflitos. Leader c o aceita ours/current; Leader c t aceita theirs/incoming; Leader c b aceita a base no conflito selecionado.

Edite o resultado diretamente quando precisar combinar os lados. Salve, revise e faça stage apenas dos arquivos resolvidos. :ForgeDiff abre a revisão de alterações a qualquer momento.

<CodeBlock code={':ForgeConflicts'} />

> Escolher um lado é sempre sua decisão. Nenhum conflito é resolvido automaticamente.

## Buscar, navegar e substituir

1. Pressione **Ctrl F** ou **Leader f b** para buscar neste arquivo. **Leader f r** busca no projeto.
2. Digite em **Find**, pressione **Tab** e preencha **Replace with**.
3. Use **Tab** para visitar cada opção e botão. **Espaço** ou **Enter** alterna a opção focada.
4. Use **Previous** e **Next / skip** para acompanhar as ocorrências sem alterar nada.
5. Escolha **Replace one** para substituir a atual e avançar. A janela continua aberta. Repita ou pule o que quiser manter.
6. Use **Replace all** somente para alterar todas. Confirme explicitamente; Cancel começa selecionado.

A ocorrência selecionada é destacada no editor sem tirar seu foco. **Enter em
Find, Replace with ou nos resultados avança para a próxima**; não fecha a janela.
A busca no arquivo inclui texto não salvo. Salve antes de aplicar substituições,
para que nenhuma edição pendente seja gravada silenciosamente.

| Tecla                     | Ação                                     |
| ------------------------- | ---------------------------------------- |
| Tab / Shift Tab           | Visitar cada campo, opção e botão        |
| Espaço / Enter em opção   | Alternar aquela opção                    |
| Enter / F3                | Próxima ocorrência, sem substituir       |
| Shift Enter / Shift F3    | Ocorrência anterior                      |
| Ctrl R                    | Substituir a selecionada e avançar       |
| Ctrl A                    | Pedir substituição de todas              |
| Ctrl Enter nos resultados | Abrir resultado e fechar a janela        |
| F2                        | Focar Replace with                       |
| F8 / Alt C                | Alternar maiúsculas/minúsculas (Aa)      |
| F4 / Alt W                | Alternar palavra inteira                 |
| F5 / Alt R                | Alternar busca por regex                 |
| F6                        | Alternar arquivo/projeto                 |
| Esc                       | Sair da digitação; novamente para fechar |

Nos resultados, **y** substitui e avança, **n** pula e **N** volta.

A substituição é literal: `$1` não expande grupos. Texto vazio remove a ocorrência.
Resultados alterados e buffers não salvos bloqueiam a aplicação. Com mais de
2000 ocorrências, refine a busca antes de substituir todas.
